# Support days ("d") in parse and format

I time multi-day batch jobs and log their run time with `format`. A job that ran 51 hours prints `51h`, which is hard to read, and `parse('2d')` throws.

Please add a `d` unit, 24 hours:

- `parse('2d')` gives `172800000`
- `parse('1d12h')` gives `129600000`
- `format(183_600_000)` gives `2d 3h`
