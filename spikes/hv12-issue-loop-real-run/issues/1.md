# parse("1h 30m") throws a TypeError

`parse` fails on a span with a space between its units, which is how most people write it.

Steps:

```js
import { parse } from 'durations';
parse('1h 30m');
```

Error:

```
TypeError: Cannot read properties of null (reading '1')
    at Module.parse (src/index.js:14:26)
```

Expected: `5400000`, the same as `parse('1h30m')`.
